- Top Analytics Cards: Right ABOVE the ledger spreadsheet grid, add 3 analytics summary cards that dynamically calculate based on the current filters: 'Total Expected Revenue', 'Total Revenue Collected', and 'Total Outstanding Debt'.
- Simplify Edit Student Modal: Strip all financial lists, summaries, except amoint owed and fee checkboxes out of the Edit Student modal (image_13dd42.jpg) to eliminate visual mess. Keep only Name, Class, and Status toggles. Add a single button at the bottom: 'Manage Fees & View Ledger' which closes the modal and instantly redirects the admin to that student's row in the master ledger grid.
- Ledger-Based Fee Assignment: Add an 'Actions' dropdown menu button to each row in the Master Student Ledger grid with an option for 'Manage Fees'. Clicking it opens a clean modal/side-panel dedicated entirely to assigning additional fee templates to that specific student. Saving updates the database and refreshes the ledger grid rows instantly.
